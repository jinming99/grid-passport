## Open questions

- **Interviewer SDK fallback path (2.1)**: when no Claude Code host session is present, desktop needs *some* transport. Options: (a) ship with a bundled Agent SDK and prompt the user for a key on first run, (b) require a host Claude Code session and error out otherwise. Recommend (b) for v0 — matches the "no API-key UX" decision in `#7`; revisit if applicants without Claude Code try to use the app.
- **Explainer validator scope (2.2)**: the paired validator checks the narration contains no raw-private-field regex matches. Does it also check role-voice adherence? Recommend: structural-only in v0 (same pattern as Interviewer's validator); voice quality is the substrate-metrics job + the Prometheus judge in sim-bench.
- **Utility binary identity (3.1)**: crate name? Recommend `grid-passport-utility` / identifier `app.gridpassport.utility` / window 1180×760 (same as applicant). Workspace membership under `apps/utility/`.
